# 코드 한입 — JavaScript 첫걸음

한국어로 된 활동 중심의 초보자용 코딩 학습 페이지입니다. 글을 읽는 데 그치지 않고, 브라우저에서 코드를 직접 고치고 실행하며 JavaScript 기초를 익힙니다.

## 학습 내용

1. `console.log()`로 첫 문장 출력하기
2. 변수와 문자열 연결하기
3. 숫자 계산하기
4. `if` 조건문으로 선택하기
5. `for` 반복문으로 세기
6. 함수를 만들고 호출하기
7. 배열과 `for...of` 사용하기
8. 배운 내용으로 장바구니 합계 만들기

## 실행하기

`index.html`을 브라우저에서 열면 바로 시작할 수 있습니다. 별도의 설치나 빌드 과정은 필요하지 않습니다. 코스 진도와 작성 중인 코드는 브라우저의 `localStorage`에 저장됩니다.

GitHub Pages로 공개하려면 저장소 설정에서 Pages를 활성화하고 배포 소스로 `main` 브랜치의 루트 디렉터리를 선택하세요.
